title: Fuel interface data file
definition: "The file in which the fuel system module delivers its data to the app (data/fuel-module.json): the fuel density in kg/L; for each aircraft type the fuel lever arm, the one lever arm in m at which the usable fuel acts, and the usable fuel capacity, the most usable fuel in litres (L) the tanks hold; and for each aircraft the reported usable fuel quantity in L with its report time in UTC."
