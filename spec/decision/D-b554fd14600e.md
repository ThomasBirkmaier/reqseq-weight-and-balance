title: Type data of the Halcyra HC-4
rationale: The aircraft is invented (the name Halcyra was checked not to be a real aircraft type). The values are plausible for a small four-seat single-engine aircraft. Type data stays in this decision and never in a system requirement, so that requirements stay valid when the data changes. A new weighing report changes this decision and the data file of the app in one pull request.
---

The core product supports one invented aircraft type, the **Halcyra HC-4**, a four-seat single-engine aircraft. Datum: a vertical plane 1.300 m forward of the front face of the firewall. All lever arms in m aft of the datum.

| Item | Mass | Lever arm |
| --- | --- | --- |
| Front seats (pilot and passenger) | 0 to 230 kg | 2.300 m |
| Rear seats | 0 to 200 kg | 3.250 m |
| Baggage compartment | 0 to 50 kg | 3.950 m |
| Maximum take-off mass | 1150 kg | |
