title: Fuel entries prefilled from the fuel system module
rationale: The pilot enters what is on board including fuel at take-off; the module reports the quantity, the pilot checks it. The planned fuel burn has no default, so that a landing check is never made from a figure the pilot did not enter.
requirement-type: functional
acceptance-criteria:
  - Given the fuel interface data file reports 142 L for HC4-01, when the pilot selects HC4-01, then the entry "Usable fuel at take-off (max 170 L)" shows 142.
  - Given the aircraft HC4-01 is selected, when the app is shown, then the entry "Planned fuel burn" is empty.
  - Given the fuel interface data file reports 78 L for HC2-01, when the pilot selects HC2-01 in the HC-2 build, then the entry "Usable fuel at take-off (max 104 L)" shows 78.

If an aircraft is selected, the system shall provide the entries "Usable fuel at take-off" and "Planned fuel burn" in L, with the usable fuel at take-off prefilled with the quantity reported by the fuel system module for that aircraft.
