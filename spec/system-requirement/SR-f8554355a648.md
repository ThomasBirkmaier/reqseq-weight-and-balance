title: Offline notice with the date of the data
rationale: "Without network the app cannot know that newer aircraft data exists; the pilot must see the date on which the mass and balance data of the selected aircraft last changed (release 1 validation decision, point 4; client decision in release 3). The fleet data file holds no other change date, so the weighing date of the selected aircraft stands for it. The time of a fuel report never counts: the app shows it with the reported fuel quantity at all times. Release 2 showed the newest date of both data files, a fuel report date."

If the app is open without a network connection with an aircraft selected, the system shall show the notice `Offline: aircraft data as of {date}. Check the weighing date against the aircraft documents.` with the weighing date of the selected aircraft as `{date}`.
