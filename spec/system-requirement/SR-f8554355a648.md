title: Offline notice with the date of the data
rationale: "Without network the app cannot know that newer aircraft data exists; the pilot must see the date of the data in use (release 1 validation decision, point 4). A pilot who takes old data for current gets a wrong limit indication. The fuel report time is not repeated in the notice: the app shows it with the reported fuel quantity at all times."
requirement-type: functional
acceptance-criteria:
  - "Given the newest date in the fleet data file and in the fuel interface data file is 2026-11-02, when the network is switched off while the app is open, then the app shows \"Offline: aircraft data as of 2026-11-02. Check the weighing date against the aircraft documents.\""
  - Given the notice of the first criterion is shown, when the network is back, then the app hides the notice.

If the app is open without a network connection, the system shall show the notice "Offline: aircraft data as of <date>. Check the weighing date against the aircraft documents." with the newest date of the fleet data file and of the fuel interface data file.
