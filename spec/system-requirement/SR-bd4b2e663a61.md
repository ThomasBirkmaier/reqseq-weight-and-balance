title: Aircraft data from the fleet data file

requirement-type: interface
acceptance-criteria:
  - Given the fleet data file lists HC4-02 with 778 kg, 2.236 m and the weighing date 2026-09-14, when the pilot selects HC4-02, then the app shows "Empty mass 778 kg at 2.236 m, weighed 2026-09-14".
  - Given a fleet data file in which HC4-02 has the empty mass 781 kg, when the app is built from it and the pilot selects HC4-02, enters 0 kg in every loading station, 0 L usable fuel at take-off and 0 L planned fuel burn, then the total mass at take-off shows 781 kg.
