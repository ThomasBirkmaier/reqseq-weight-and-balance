  - Given the aircraft HC4-01 is selected with 0 L usable fuel at take-off and 0 L planned fuel burn, when the pilot enters 0 kg front seats, 0 kg rear seats and 0 kg baggage compartment, then the total mass at take-off shows 765 kg.
