title: Message for an invalid mass entry
rationale: A mass outside the range of a loading station, a negative mass or a text would make the total mass and the centre of gravity wrong; the pilot has to see which entry is wrong.
requirement-type: functional
acceptance-criteria:
  - Given the aircraft HC4-01 is selected, when the pilot enters 201 in "Rear seats", then the message "Enter 0 to 200 kg" is shown next to "Rear seats".
  - Given the aircraft HC4-01 is selected, when the pilot enters -5 in "Front seats", then the message "Enter 0 to 230 kg" is shown next to "Front seats".
  - Given the aircraft HC4-01 is selected, when the pilot enters 7.5 in "Baggage compartment", then the message "Enter 0 to 50 kg" is shown next to "Baggage compartment".

If a mass entered for a loading station is not a whole number from 0 kg to the maximum mass of that loading station, the system shall show the message "Enter 0 to <maximum> kg" next to that entry.
