title: Pilot's fuel figure
rationale: The pilot is responsible for the fuel figure (condition of the client's confirmation of release 1) and must see at once whether the check uses the reported or the own figure.
requirement-type: functional
acceptance-criteria:
  - Given the aircraft HC4-01 is selected with the reported 142 L, when the pilot changes "Usable fuel at take-off" to 100, then the app shows "Pilot's figure (fuel system module reported 142 L)" next to the entry.
  - Given the aircraft HC4-01 is selected, when the pilot enters 160 kg front seats, 0 kg rear seats, 20 kg baggage compartment, 0 L planned fuel burn and changes the usable fuel at take-off from 142 L to 100 L, then the total mass at take-off shows 1017 kg.
  - Given the note of the first criterion is shown, when the pilot changes the entry back to 142, then the note is not shown.

If the pilot changes the usable fuel at take-off to a figure other than the reported quantity, the system shall calculate with the pilot's figure and show the note "Pilot's figure (fuel system module reported <quantity> L)" next to the entry.
