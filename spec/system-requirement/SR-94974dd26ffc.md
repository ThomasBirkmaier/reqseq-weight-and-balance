title: Reported fuel quantity with its report time
rationale: The report time is the pilot's only cue that a fuel report is old and the tanks must be dipped (client); a pilot who takes an old report for the fuel on board gets a wrong limit indication.
requirement-type: functional
acceptance-criteria:
  - "Given the fuel interface data file reports 142 L for HC4-01 at 2026-11-02T05:40:00Z, when the pilot selects HC4-01, then the app shows \"Reported by the fuel system module: 142 L at 2026-11-02 05:40 UTC\"."
  - "Given the fuel interface data file reports 96 L for HC4-02 at 2026-11-02T05:15:00Z and HC4-01 is selected, when the pilot selects HC4-02, then the app shows \"Reported by the fuel system module: 96 L at 2026-11-02 05:15 UTC\"."
  - "Given the fuel interface data file reports 78 L for HC2-01 at 2026-11-02T05:50:00Z, when the pilot selects HC2-01 in the HC-2 build, then the app shows \"Reported by the fuel system module: 78 L at 2026-11-02 05:50 UTC\"."

If an aircraft is selected, the system shall show the usable fuel quantity reported by the fuel system module for that aircraft with its report time in UTC to the minute.
