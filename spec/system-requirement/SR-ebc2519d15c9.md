title: Aircraft without a fuel report
rationale: Without a report the app has no fuel figure to prefill; an entry prefilled with a figure, for example 0 L, would give a limit indication for fuel the pilot never entered. The supplier delivers one report per aircraft; this requirement covers a fleet data file with an aircraft the supplier does not know yet.
requirement-type: functional
acceptance-criteria:
  - key: w7qh
    text: Given a fuel interface data file without a report for an aircraft of the build, when the pilot selects that aircraft, then the entry "Usable fuel at take-off" is empty and the app shows "No report of the fuel system module" next to it.
  - key: f090
    text: "Given the aircraft of the first criterion is selected with a mass in every loading station and the planned fuel burn entered, when the usable fuel at take-off is still empty, then the take-off limit indication shows \"Check not complete: fill in or correct the marked entries\"."

If the fuel interface data file holds no report for the selected aircraft, the system shall leave the entry "Usable fuel at take-off" without a value and show the statement "No report of the fuel system module" next to it.
