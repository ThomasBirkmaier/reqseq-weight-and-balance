title: Fuel mass and lever arm from the fuel interface data file
rationale: The supplier's fuel system module states how much fuel is on board and where its mass acts; the app takes these values only from the interface data file, so that a new delivery of the supplier reaches the pilots with the next build. Wrong fuel data gives a wrong limit indication.
requirement-type: interface
acceptance-criteria:
  - Given the fuel interface data file states 0.72 kg/L and 2.350 m for the HC-4, when the pilot selects HC4-01 and enters 0 kg in every loading station, 100 L usable fuel at take-off and 0 L planned fuel burn, then the total mass at take-off shows 837 kg and the centre of gravity at take-off 2.231 m.
  - Given the fuel interface data file states 0.72 kg/L and 2.100 m for the HC-2, when the pilot selects HC2-01 in the HC-2 build and enters 0 kg in every loading station, 50 L usable fuel at take-off and 0 L planned fuel burn, then the total mass at take-off shows 676 kg and the centre of gravity at take-off 2.147 m.
  - Given a fuel interface data file in which the HC-4 fuel lever arm is 2.400 m, when the app is built from it and the pilot selects HC4-01 with 0 kg in every loading station, 100 L usable fuel at take-off and 0 L planned fuel burn, then the centre of gravity at take-off shows 2.235 m.

If the fuel interface data file states a fuel density and a fuel lever arm for the aircraft type, the system shall add the usable fuel to the loading with the mass of its volume times that fuel density at that fuel lever arm.
