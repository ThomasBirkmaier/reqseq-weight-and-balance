title: Unsupported fuel interface version
rationale: A major version other than 1 means that a field changed its meaning or was removed (interface decision of the supplier); a malformed version hides such a change. Fuel figures of a changed meaning would give a wrong limit indication. Release 2 accepted every version beginning with "1.", also the malformed "1.0".
requirement-type: interface
acceptance-criteria:
  - key: dzj0
    text: Given a fuel interface data file with the interface version "2.0.0", when the app is built from it and opened, then it offers no aircraft for selection and shows "The app could not load its data. Reload the page."
  - key: fd7z
    text: Given a fuel interface data file with the interface version "1.0", when the app is built from it and opened, then it offers no aircraft for selection and shows "The app could not load its data. Reload the page."
  - key: bcrp
    text: Given a fuel interface data file with the interface version "1.1.0" and otherwise the content of the delivered file, when the app is built from it and opened, then it offers the aircraft of its build for selection.

If the interface version of the fuel interface data file does not have the form `1.minor.patch` with whole numbers as minor and patch, the system shall refuse that file and offer no aircraft for selection.
