title: Invalid or incomplete loading used for a limit indication
rationale: A mass above the maximum of a loading station, a negative value or a value that is not a number would make the calculated total mass and centre of gravity wrong without the pilot noticing.
severity: hazardous
---

The system calculates and shows a limit indication from a loading that contains a value which is not a valid mass for its loading station.
